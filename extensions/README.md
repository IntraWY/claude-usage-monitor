# Chrome extensions เดิม

สองตัวนี้ทำงานแยกกันและไม่ใช่ส่วนประกอบของโปรแกรม Windows

- `usage-monitor/`: floating window สำหรับ Claude usage; manifest version 1.2.0
- `session-optimizer/`: วางแผน ping/session และตั้ง Chrome alarms; manifest version 1.0.0

โหลดแต่ละโฟลเดอร์ผ่าน Chrome → Extensions → Developer mode → Load unpacked
ชื่อไฟล์ภายในและเส้นทางที่ manifest อ้างอิงยังเหมือนเดิม การย้ายโฟลเดอร์ต้องเลือก Load unpacked จากตำแหน่งใหม่
